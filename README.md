# Astra Select Logo Fix

Fixes the missing "Select Logo" or "Change Logo" option in Astra Theme Customizer and restores WordPress custom logo functionality.

<img width="2026" height="1668" alt="image" src="https://github.com/user-attachments/assets/4c7a7800-7152-4074-b5b3-fa949ad039e0" />
Source: Astra (https://wpastra.com/docs/manage-site-identity-and-logo/)

## Description

Some Astra Theme installations may experience an issue where:

- The "Select Logo" button is missing
- The "Change Logo" button does not work
- Logo upload is unavailable in the Customizer
- The logo does not display in the website header

This plugin restores WordPress custom logo support, forces Astra to recognize the logo functionality, and adds a fallback logo uploader inside the Customizer.

## Features

✅ Fixes missing "Select Logo" button in Astra Theme

✅ Restores WordPress Custom Logo support

✅ Adds fallback logo upload option

✅ Forces logo display in Astra header

✅ Works with Astra Free and Astra Pro

✅ No Astra core file modifications required

## Problem Example

If you open:

Appearance → Customize → Site Identity

and you cannot see:

- Select Logo
- Change Logo
- Logo Upload Option

this plugin will restore the functionality.

## Installation

1. Download the plugin.
2. Upload it to:

```
wp-content/plugins/
```

3. Activate the plugin.
4. Go to:

```
Appearance → Customize → Site Identity
```

5. Upload your logo.

## Requirements

- WordPress 5.0+
- Astra Theme
- PHP 7.4+
